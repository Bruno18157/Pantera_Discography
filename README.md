# 🎸 Pantera Discography Web Site

A clean, responsive, and minimalist fan-made website dedicated to the legendary groove metal band **Pantera**. This project showcases their complete discography, capturing the raw energy of the band through a simple web interface.

## 🚀 About the Project

The goal of this site is to compile and present Pantera's iconic album history. 

### 📌 What's Inside:
* **The Albums:** A chronological list of Pantera's studio releases.
* **Tracklists & Details:** Quick insights into their heaviest tracks and eras.
* **Visual Identity:** A design inspired by the band's aggressive, classic aesthetic.

## 🛠️ Built With

This is a lightweight, pure front-end project made using only:
* **HTML5** (`index.html`) - Clean, semantic markup for the content structure.
* **CSS3** (`style.css`) - Custom styling, layout, and responsive design.

## 📁 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Open the `index.html` file directly in any modern web browser.
